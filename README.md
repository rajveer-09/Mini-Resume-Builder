# Mini Modern Resume Builder ✨

A small, focused **resume-builder web app** with an interactive AI assistant.  
Designed for **quick resume generation**, **live preview**, and a **clean modern UI**.

---

## 🚀 Features

- AI-driven content generation for resume sections  
- Live resume preview while editing  
- Small, modular React components for easy customization  
- Fast development and build setup with Vite  

---

## 🧰 Tech Stack

- **React + TypeScript**
- **Vite** (development server & build tool)
- **Gemini API** (AI content generation)
- **Netlify** (deployment)
